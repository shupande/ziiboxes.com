Fragrance gift set packaging needs a clear layout for every item: bottle, sample vial, card, sleeve or accessory. The box and insert should be approved together.

![Drawer box packaging for premium perfume gift sets](/images/drawer-boxes.jpg)

## Gift set checks

| Detail | Packaging check |
| --- | --- |
| Main bottle | Insert support and opening direction |
| Sample vials | Small cutouts or dividers |
| Card or leaflet | Flat position in the set |
| Premium finish | Foil, embossing or soft-touch surface |
| Carton plan | Protect finished gift boxes in export cartons |

If the gift set changes by season, keep the outer structure stable and update inserts or sleeves where possible.
