Apparel packaging should start with the folded product size. A shirt, socks, underwear set or hoodie may need very different packaging even when the brand artwork is similar.

![Custom apparel packaging boxes for clothing brands](/images/industries/custom-apparel-packaging-boxes.jpg)

## Quote checklist

| Detail | What to confirm |
| --- | --- |
| Garment type | Shirt, socks, underwear, activewear or accessory |
| Folded size | Packed length, width, height and weight |
| Package type | Mailer box, sleeve, belly band, folding carton or card |
| Inserts | Care card, size card, thank-you card or label |
| Handoff route | China factory, packer, warehouse or freight route |

If a China garment factory will pack the goods, send their receiving address and packing steps before production.
