Candle gift set packaging should hold every item in a clear position. Candles, matches, cards, fragrance samples and accessories all need a layout before the box size is approved.

Send the full set list, item sizes, item weights, quantity, gift box style and insert idea before requesting a quote.

![Four scented candle jars packed in a custom gift box insert](/images/guides/supplier-four-scent-candle-gift-box.jpg)

## Gift set insert planning

| Set detail | Packaging check |
| --- | --- |
| Multiple candle jars | Use dividers or individual cutouts to avoid contact |
| Candle plus matches | Keep matches away from glass pressure points |
| Candle plus card | Leave a flat, visible card position |
| Mixed scents | Keep SKU or scent labels clear during packing |
| Premium gift set | Consider rigid box, drawer box or lid-and-base structure |

## Keep the layout stable

Confirm the product arrangement before sampling. If the insert changes, the box size, carton size and artwork may need to change too.

Paper inserts and dividers can support a paper-based brand policy, but heavier jars may need extra testing or stronger protection.
