Apparel packaging inserts should support the order, not slow packing. Care cards, size cards and thank-you cards need a clear position in the box or sleeve.

![Printed ecommerce packaging prepared with insert cards](/images/guides/supplier-ecommerce-mailer-boxes.jpg)

## Insert planning

| Insert | Useful for |
| --- | --- |
| Care card | Washing, fabric and return notes |
| Thank-you card | DTC brand message or discount code |
| Size card | Socks, underwear and multi-size products |
| Belly band | Holding folded garments together |
| Product label | SKU, barcode or warehouse receiving |

If packing happens at a China factory, provide one clear photo or diagram showing where every card and label goes.
