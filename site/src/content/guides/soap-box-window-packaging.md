Soap box window packaging helps customers see color, texture or handmade details. It works best when the bar appearance helps sell the product.

![Soap boxes with retail window packaging](/images/products/custom-window-boxes.jpg)

## Window planning

| Window detail | Why it matters |
| --- | --- |
| Window size | Shows product but keeps box strength |
| Window shape | Should match artwork and cutting limits |
| Label area | Keep scent and ingredient text readable |
| Bar position | Window must align with the packed bar |
| Carton packing | Windows can be easier to scratch or dent |

Skip the window if the soap color changes often or if a label carries most of the selling message.
