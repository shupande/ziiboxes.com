Good artwork files make quoting, sampling and production faster. If the file is incomplete, the supplier may need extra time to confirm size, bleed, fonts or color references. A clean file also reduces the chance of mistakes after the sample is approved.

## Basic file requirements

Send an editable file when possible. AI, PDF or other print-ready formats are common. Include the dieline, bleed, fold lines, cut lines and safety margins.

Before sending artwork, check:

- The dieline matches the final box size.
- Bleed extends beyond the cut line.
- Important text and logos stay inside the safe area.
- Fold lines and cut lines are clearly marked.
- Inside print and outside print are separated or clearly labeled.

## Color and image checks

Use CMYK for standard print artwork. If brand color matching is important, include Pantone references. Images should be high enough resolution for print.

If the box uses kraft paper, remember that colors may look different from printing on white paperboard. Ask for a sample if color is important.

## Text and barcode checks

Outline fonts or include the font files. Check small text, barcode size and legal copy before sampling.

| Item | Why it matters |
| --- | --- |
| Fonts outlined | Prevents missing-font changes when the file is opened |
| Barcode tested | Helps avoid scanning problems on retail or logistics labels |
| Small text checked | Keeps ingredients, claims and legal copy readable |
| Pantone listed | Helps match brand colors more closely |
| Finish layer marked | Shows where foil, embossing or spot UV should be applied |

## What to send if artwork is not ready

You can still request an early quote without final artwork. Send the box style, size, quantity, product photo, reference packaging and destination country. The first quote can estimate structure and material before the final file is prepared.

## FAQ

### Can I send only a logo and product photo?

Yes for an early estimate. For production, a print-ready file and confirmed dieline are needed.

### Should I approve a sample before bulk production?

Yes. The sample lets you check size, folding, color, finish and text before the full order is made.
