Custom candle box packaging should start with the candle jar, not the artwork. Jar size, weight, glass thickness, lid style and sales channel all affect the box structure and insert.

Send candle photos, jar dimensions, jar weight, quantity, artwork stage, destination and packing route before asking for a quote.

![Custom candle packaging boxes for scented candle brands](/images/industries/custom-candle-boxes.jpg)

## Candle packaging checklist

| Item | What to confirm |
| --- | --- |
| Candle type | Glass jar, tin, ceramic vessel, pillar candle or gift set |
| Product size | Jar diameter, height, lid size and packed weight |
| Box style | Folding carton, rigid box, drawer box, sleeve or mailer |
| Insert need | Paper insert, divider, snug carton fit or stronger cushioning |
| Label area | Product label, warning label, barcode or scent sticker |
| Packing route | China supplier, packer, warehouse or freight forwarder |
| Carton plan | Units per carton, carton size, carton weight and shipping marks |

## Before sampling

Decide whether the candle box is for retail display, ecommerce shipping, gifting or export consolidation. A retail box may still need an outer carton if the candle is fragile.

If the candle is scented, liquid-related, glass, heavy or seasonal, tell the packaging supplier early. The freight route may ask for clearer carton or product notes.
