Perfume bottle inserts should reduce movement and protect the bottle shape. The insert must be planned before the outer box size is approved.

![Custom paper inserts for perfume bottle boxes](/images/products/custom-paper-inserts.jpg)

## Insert options

| Option | Best for |
| --- | --- |
| Paperboard insert | Lighter glass bottles and retail cartons |
| Wrapped insert | Premium fragrance box presentation |
| Divider | Fragrance sets or bottle plus accessory |
| Rigid box insert | Luxury launch and gift sets |
| Outer carton | Export or ecommerce handling |

Send the bottle sample or exact size before sampling. Small bottle-shape changes can affect the insert.
