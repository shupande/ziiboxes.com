Jewelry packaging should start with the item type, size and presentation level. A ring, necklace, bracelet and gift set need different insert and box decisions.

![Custom jewelry packaging boxes with logo printing](/images/industries/custom-jewelry-boxes.jpg)

## Quote checklist

| Detail | What to confirm |
| --- | --- |
| Product type | Ring, earrings, necklace, bracelet or set |
| Insert | Paper insert, wrapped insert, card holder or velvet-style insert |
| Box structure | Folding carton, rigid box, drawer box or gift box |
| Logo finish | Printing, foil stamping, embossing or debossing |
| Carton plan | Units per carton, labels and handoff route |

Plan the insert before artwork. If the insert changes, the box size and logo position may need to change too.
