Kraft soap boxes work well when the brand wants a natural paper look. The design should account for kraft paper color because print colors will not look the same as on white paper.

![Kraft soap boxes with window cutouts](/images/guides/supplier-cardboard-soap-packaging.jpg)

## Kraft soap checks

| Detail | Watch point |
| --- | --- |
| Paper color | Affects printed color brightness |
| Window | Needs position and film discussion |
| Label | Scent and ingredient label space |
| Bar fit | Soap size tolerance and shrink wrap if used |
| Carton packing | Avoid crushing boxes in export cartons |

Keep artwork simple when using kraft paper. Strong contrast usually reads better.
