FNSKU and barcode labels should be planned before custom packaging artwork is approved. A clean, flat, scannable label area is easier to reserve during box design than after production starts.

Send the final label file when available, but tell the packaging supplier early if the product needs UPC, FNSKU, SKU sticker, warning label, carton label or warehouse label space.

![Open mailer box showing clear packaging panels for label planning](/images/guides/supplier-white-shipping-packaging.jpg)

## Common label types

| Label type | Where it may be used | What to prepare |
| --- | --- | --- |
| Product barcode | Retail product box or unit package | Barcode file and readable number |
| FNSKU label | Amazon sellable unit | Label file and SKU instructions |
| Warning label | Product box, bag or outer package | Required text from your route |
| Carton label | Master carton | Carton label file and placement notes |
| Shipping mark | Export carton | SKU, carton number, destination or receiver notes |

## Design the label area early

Keep the label area away from fold lines, heavy texture, foil, curved surfaces and dark background patterns. The exact final rule should come from your route, but the packaging design should avoid making scanning harder.

If you sell several SKUs, keep label placement consistent across sizes. This helps packing teams avoid mixing units during carton packing.

## When products are packed in China

If ZiiBoxes packs suitable products into finished boxes, send the label files, SKU list, product count per set and checking steps before packing begins. Label work should be treated as part of the packing instruction, not as a last-minute note.
